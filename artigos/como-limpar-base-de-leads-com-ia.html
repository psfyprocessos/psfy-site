Como limpar uma base de leads bagunçada usando IA

Henrique Sofiati 18 de setembro de 2026 3 min de leitura

Toda loja de carros tem uma lista de contatos que cresceu sem regra. Cada vendedor cadastra do seu jeito, o telefone vem com parênteses ou sem, a cidade vem abreviada, o mesmo cliente aparece três vezes com emails diferentes. Na hora de disparar uma campanha ou medir carteira por vendedor, a base não responde.

Foi esse o problema que resolvemos em uma concessionária multimarcas. O objetivo não era só arrumar o que já existia, era garantir que todo contato novo já entrasse limpo.

Como o cadastro passou a entrar já padronizado

O contato entra por um formulário e passa por três etapas antes de virar cadastro válido. Primeiro um código padroniza os dados, colocando telefone, estado, CEP e site num formato único. Depois o sistema procura se aquela pessoa já existe na base, mesmo que o email seja diferente, comparando telefone, nome e endereço. Por último uma IA com acesso à internet confere se a empresa informada existe de verdade, encontra o site oficial e aponta divergências, como uma cidade que não bate com o CEP.

Quando está tudo certo, o contato é aprovado sozinho e cai na categoria correta. Quando existe dúvida, ele fica parado com uma etiqueta e um resumo do motivo, para alguém revisar em poucos segundos.

As ferramentas usadas na automação

  • Pipefy para a base de contatos, as etapas e o cadastro de empresas
  • Zapier para orquestrar o fluxo entre as etapas
  • API do Claude com busca na web para a validação dos dados
  • Código em JavaScript rodando dentro do Zapier para padronização e detecção de duplicados
  • API GraphQL do Pipefy para leitura e gravação nos cadastros

O que ainda vamos melhorar

O maior ponto de ajuste é a régua de confiança. Empresa pequena com pouca presença na internet acaba indo para revisão mesmo estando correta, e isso só calibra com volume real. Também queremos reduzir o custo por contato usando um modelo mais leve nas checagens simples, e evoluir a detecção de duplicados para sugerir a união dos cadastros, e não só apontar a suspeita.

Por que base de leads duplicados custa venda

Base suja não é problema de organização, é problema de venda. Campanha que não chega, vendedor ligando para cliente que já é de outro, relatório que ninguém confia. Automatizar a entrada custa muito menos do que limpar a base uma vez por ano.
